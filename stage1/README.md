# ПР22. Визуализатор графа зависимостей Cargo — Этап 1

## 1. Общее описание

Учебный проект (вариант 22): CLI-инструмент, который собирает сведения
о зависимостях пакетов Cargo (Rust) и визуализирует их в виде графа.

На этапе 1 реализован минимальный прототип: разбор параметров командной
строки, их проверка и вывод в формате ключ-значение.

Язык реализации: Python 3, только стандартная библиотека.

## 2. Параметры запуска

| Параметр      | Назначение                                   | По умолчанию |
|---------------|----------------------------------------------|--------------|
| `--package`   | Имя анализируемого пакета                    | —            |
| `--url`       | URL репозитория или путь к тестовому файлу   | —            |
| `--test-mode` | Режим работы с тестовым репозиторием (флаг)  | выключен     |
| `--version`   | Версия пакета                                | `latest`     |
| `--output`    | Имя файла с изображением графа               | `graph.png`  |
| `--filter`    | Подстрока для исключения пакетов из анализа  | пусто        |

## 3. Обработка ошибок

Проверяются все настраиваемые параметры:

- пустое имя пакета; имя с недопустимыми символами (допустимы строчные
  латинские буквы, цифры, `-`, `_`, `.`; в тестовом режиме — одна
  заглавная буква A–Z);
- пустой URL/путь; в тестовом режиме — путь к несуществующему файлу;
- некорректная версия (ожидается `latest` или числа вида `1.2.3`);
- имя файла изображения без расширения `.png`.

При ошибках приложение печатает сообщения и завершается с кодом 1.

## 4. Структура проекта

```
src/      — исходный код (main.py, config.py)
tests/    — модульные тесты (unittest)
run.bat   — запуск и тесты для Windows
run.sh    — запуск и тесты для Linux
```

## 5. Запуск и тесты

Сборка не требуется (интерпретируемый язык). Требуется Python 3.8+.

Windows: запустите `run.bat`. Linux: `sh run.sh`.

Программа работает в интерактивном режиме и не закрывается, пока не
введена команда `exit`. После приглашения `>` можно вводить:

- строку аргументов программы, например
  `--package serde --url https://index.crates.io`;
- `test` — запуск модульных тестов;
- `exit` — выход.

Пустой Enter просто показывает приглашение заново.

## 6. Примеры использования

Все команды вводятся после приглашения `>` (пример для Windows;
в Linux то же самое после `sh run.sh`).

1. Успешный запуск (значения по умолчанию для version и output):

```
> --package serde --url https://index.crates.io
Параметры запуска:
  package = serde
  url = https://index.crates.io
  test_mode = False
  version = latest
  output = graph.png
  filter =
```

2. Ошибочный запуск (плохая версия):

```
> --package serde --url https://index.crates.io --version 1.a
Параметры запуска:
  ...
Ошибка: недопустимая версия: 1.a
```

3. Пустое имя пакета:

```
> --url https://index.crates.io
Ошибка: не задано имя пакета (--package)
```

4. Имя файла изображения без .png:

```
> --package serde --url https://x --output graph.jpg
Ошибка: файл изображения должен иметь расширение .png
```

5. Запуск тестов:

```
> test
Ran 7 tests in 0.023s

OK
```

6. Выход:

```
> exit
```
